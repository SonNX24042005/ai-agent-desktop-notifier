# Notification icons

This directory contains the notification icon assets for `anoti`:

## Vector SVG files (source & scalable icons)
- `anoti.svg`: Default fallback application icon (MIT License).
- `claude.svg`: Claude icon from Simple Icons (CC0 1.0 Universal / Anthropic mark).
- `codex.svg`: OpenAI Codex icon from Simple Icons (CC0 1.0 Universal / OpenAI mark).

## Raster PNG files (runtime notifications)
- `anoti.png`: Default fallback application icon (128x128 pixel, MIT License).
- `claude.png`: Claude icon rendered with official brand color `#D97757` (128x128 pixel).
- `codex.png`: OpenAI Codex icon rendered with official brand color `#412991` (128x128 pixel).
- `antigravity.png`: Official Google Antigravity icon from https://antigravity.google/apple-touch-icon.png (180x180 pixel).

See [docs/icons.md](../../docs/icons.md) for full licensing, pinned URLs, SHA-256 hashes, brand color metadata, and trademark details.
